ZEPHRA

Build Insight

Provides real-time monitoring of construction progress.

Uses AI/ML models to verify completion at every stage and cross-check with blueprints.

Ensures fund transparency by tracking expenditures with a secure, role-based dashboard.

Improves construction quality by detecting cracks, trapped air bubbles, hollow areas, and inadequate curing.

Prevents tender abandonment by predicting risks using machine learning trained on past project data.

Enhances worker safety by sending alerts in case of accidents and emergencies like fire accidents.

Image 1: Zephra ensures progress verification at every stage using PTZ cameras on drones for real-time monitoring and 3D imaging with LiDAR/IR sensors to analyse construction integrity from the basement depth upwards. It tracks electrical and pipeline installations step by step, cross-checking with blueprints to ensure accuracy.

Image 2: As we are in the stage of data collection, Zephra predicts tender abandonment by developing a model using dataset from SIH, initially trained on past data and later refined with live drone data. We have conducted data visualisation and EDA, cleaning irrelevant data to improve model accuracy. The insights and visualisations from the dataset help in understanding risk factors for better predictive decision-making.

Image 3:A secure dashboard with role-based access provides real-time insights into project status, fund allocation, and risk predictions.
